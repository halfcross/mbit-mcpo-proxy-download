macOS (Apple Silicon)

One-line install via Terminal, or download the app package yourself. Intel Macs are not supported in current releases.

Terminal — copy and paste
curl -fsSL https://halfcross.github.io/mbit-mcpo-proxy-download/install.sh | bash

Select the line above, paste into Terminal, press Return.

Manual install (download .dmg yourself)

Download the latest .dmg from this repo’s Releases. Open it, drag MindBehindAI to Applications, then run: 

APP="/Applications/MindBehindAI.app"
find "$APP" \( -type f -o -type d \) -exec xattr -c {} + 2>/dev/null
find "$APP" -type l -exec xattr -c -s {} + 2>/dev/null

Plain xattr -cr can error on symlinks; use the commands above. Ad-hoc signed builds may show a “damaged” warning until quarantine is cleared.
