Troubleshooting ​

Work through the symptom that matches yours.

macOS quarantine (“damaged” or “can’t be opened”) ​

Browsers tag downloaded apps. Remove the quarantine flag once (adjust the path if the app lives elsewhere):

bash
APP="/Applications/MindBehindAI.app"
find "$APP" \( -type f -o -type d \) -exec xattr -c {} + 2>/dev/null
find "$APP" -type l -exec xattr -hc {} + 2>/dev/null

Avoid plain xattr -cr on this bundle: it follows symlinks, and bundled Node’s bin/npx / npm / corepack point into lib/node_modules/…. If that subtree is absent for one architecture, xattr reports “No such file” and may fail the whole command. xattr -hc clears extended attributes on the symlink inode without resolving the target. You can also allow the app under System Settings → Privacy & Security.

Bridge will not start ​

  1. On Home, read the Built-in engine step—if it says unavailable, reinstall or contact support with the exact text.
  2. Check Logs for address already in use—another program is using the HTTP port. Change Settings → HTTP port or quit the other program.
  3. Tap Apply changes on Home after large edits under Connections.

Tools missing in Open WebUI ​

  1. Confirm the bridge is Running on Home.
  2. Confirm each connection is enabled under My connections.
  3. Re-run Sync enabled connections on Integrations → Open WebUI after editing connections.
  4. For manual setup, re-copy each Copy link—URLs change if you rename a connection.

OAuth loops or expired login ​

  1. Clear Settings → OAuth tokens, then trigger sign-in again from your assistant so the browser opens fresh.
  2. Make sure pop-up blockers are not blocking the Telekom or Microsoft login window.

Docker-required preset fails ​

Install Docker Desktop and wait until it is healthy, then retry the preset. The bridge itself does not run inside Docker.

Still stuck ​

Collect three things before contacting support:

  1. A screenshot of Home (status strip visible).
  2. The last ~30 lines from Logs.
  3. Your macOS version and whether you are on Apple Silicon or Intel.
