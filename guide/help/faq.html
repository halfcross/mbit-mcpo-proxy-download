FAQ ​

What is MindBehindAI? ​

A desktop app for macOS and Windows that runs a local assistant bridge and lets you attach connections (tools and data) for use in assistants such as ChatGPT, Open WebUI, or other MCP-capable clients.

Do I need Docker? ​

Not for the bridge. A normal install includes the engine on your computer.
Some Library presets show a Docker badge—only those presets need Docker installed.

Does my data go to MindBehind servers? ​

Your documents and tool traffic stay on your computer. The app still talks to the internet for things you expect: license checks, remote MCP endpoints you configured, OAuth in the browser, and optional Open WebUI sync when you turn it on.

Which platforms are supported? ​

PlatformInstall
macOS (Apple Silicon)Download page — Terminal script or .dmg
Windows (64-bit portable)GitHub Releases — single .exe

Linux desktop builds are not offered in this product line. Intel Macs are not supported in current macOS releases.

Where is my configuration stored? ​

macOS:

~/Library/Application Support/MindBehind/mcp-orchestrator/

Windows:

%APPDATA%\MindBehind\mcp-orchestrator\

See Data directory for a file-by-file list.

How do I update? ​

Use the download page or public releases:

  • macOS: download the new .dmg from Releases and replace the app in Applications (or use the legacy install script below).
  • Windows: download the new portable .exe and run it (replace your previous copy if you keep one folder).

You can also check About → Updates inside the app for release notes and links.

macOS (legacy Terminal install):

bash
curl -fsSL https://halfcross.github.io/mbit-mcpo-proxy-download/install.sh | bash

Prefer downloading the .dmg directly from the download page or Releases.

Can I import from Claude Desktop? ​

macOS: copy the mcpServers block from ~/Library/Application Support/Claude/claude_desktop_config.json (or similar) and use Settings → Import JSON.

Why does Windows warn or start slowly? ​

Portable builds are not code-signed yet, so SmartScreen may show “Windows protected your PC”—use More info → Run anyway after downloading from the official release page. The first launch can take 20–30 seconds while the app unpacks and Defender scans it; later starts are usually faster. Optional Defender folder exclusions and a hidden-window fix are in Troubleshooting → Windows.
