Data directory ​

MindBehindAI keeps its files in one folder on your computer. Nothing lives “inside a container” for the assistant bridge—everything is normal files you can back up.

Location ​

macOS:

~/Library/Application Support/MindBehind/mcp-orchestrator/

Windows:

%APPDATA%\MindBehind\mcp-orchestrator\

Open in Finder or Explorer ​

Use Settings → Data Directory → Open, or the File → Open Data Folder menu entry.

What the files mean ​

File / folderPurpose
servers.jsonAll connections (names, commands, enabled flags).
config.jsonGenerated bridge configuration (rebuilt when you start or apply changes).
orchestrator-settings.jsonPort, advanced flag, and related app settings.
license/Encrypted license material.
oauth-tokens/Saved OAuth sessions for providers such as Telekom or Microsoft.
.mindbehind-docker-cli/Cached helper for presets that still call Docker on the host.

Backups ​

The app keeps automatic backups of servers.json. For your own backup, copy at least servers.json and orchestrator-settings.json before big experiments.

Moving to a new computer ​

  1. Copy the whole mcp-orchestrator folder into the same path on the new machine (see Location above).
  2. Install MindBehindAI there and launch it.

You may need to re-activate your license if the device identity changes—contact MindBehind IT if activation fails.
