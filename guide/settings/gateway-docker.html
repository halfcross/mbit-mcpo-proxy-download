Gateway & Docker Settings ​

The Settings page lets you configure how the gateway runs. Click Settings in the sidebar to access it.

HTTP port ​

The port the gateway listens on. Default: 8000.

  • All server URLs use this port (e.g., http://localhost:8000/telecontext).
  • Change it if port 8000 is already used by another application.
  • Valid range: 1024–65535.
  • Changing the port automatically restarts the gateway container.

Memory limit ​

Control how much RAM the Docker container can use.

ValueMeaning
0No limit — the container can use as much memory as Docker allows
64 or higherHard limit in MiB (minimum: 64 MiB)

Increase this if you're running resource-intensive MCP servers (like Local RAG with large documents). Requires Apply & Restart.

CPU limit ​

Control how many CPU cores the container can use.

ValueMeaning
0No limit — uses all available cores
0.5, 1, 1.5, etc.Fractional core limit

Useful if you want to keep CPU usage down while running other applications. Requires Apply & Restart.

Saving changes ​

Click Save after changing any setting. Port changes trigger an automatic restart. Memory and CPU changes require a manual Apply & Restart from the Dashboard.
