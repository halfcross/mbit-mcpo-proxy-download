License Management ​

Your MindBehind license key is entered during first launch and managed in Settings.

Viewing your license status ​

Go to Settings. The License key section shows:

  • Status — Active, Invalid, or No license key
  • Stored key ends with — the last few characters of your key for reference

Updating your key ​

  1. Paste a new key into the New license key field.
  2. Click Save & validate.
  3. The app validates the key online and updates the status.

Re-checking ​

If the validation server was temporarily unreachable, click Re-check now to retry validation with the stored key.

Removing your key ​

Click Remove stored key to clear the license from this device. The app returns to the activation overlay and the gateway stops.

How validation works ​

  • The key is validated online when you activate it.
  • While the app is running, it re-validates every 5 minutes.
  • If the server is temporarily unreachable, the last known state is used.
  • If the key becomes invalid (expired, revoked, or activated on another device), the gateway stops and the activation overlay reappears.
  • An internet connection is required for the initial activation and periodic re-validation.

Privacy

Only your license key and a device identifier are sent to the MindBehind validation server. No usage data, server configurations, or document contents are transmitted.
