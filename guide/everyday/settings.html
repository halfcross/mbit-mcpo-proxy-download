On this page

Settings ​

Settings covers your license, the assistant bridge port, where files live on disk, OAuth resets, and optional JSON import.

License ​

  • Paste a new key and tap Save & validate when your subscription changes.
  • Re-check now forces an online validation.
  • Remove stored key signs you out of the licensed features.

The full key is never shown—only a short suffix.

Gateway ​

  • Advanced mode — shows technical names (for example raw transport labels) and extra tools such as viewing generated config. Leave off unless support asks you to turn it on.
  • HTTP port on this Mac — every Copy link URL uses this port (default 8000). Changing it restarts the bridge.

Tap Save settings after edits.

Data Directory ​

Shows the folder where MindBehindAI stores servers.json, generated config, and related files. Open jumps to it in Finder.

Privacy and security ​

OAuth tokens ​

Saved sign-ins keep Telekom, Microsoft, and similar logins working between app restarts. Clear tokens if you switched accounts, something expired, or you want a clean login.

Sign-in always happens in your normal web browser, not inside the small MindBehind window.

The same Settings scroll also contains Import configuration (below). This screenshot shows OAuth tokens and the Import area together—use Clear OAuth tokens here, and scroll to the JSON box for the next section.

Import JSON (mcp.json) ​

For migrating from another MCP host:

  1. Paste JSON in the usual shape (mcpServers or servers, optional inputs and ${input:id} placeholders).
  2. Tap Analyze (bottom of the Import area in the screenshot above).

This path is aimed at power users. Everyone else should use Connections → Library.
