Open WebUI ​

Use this page when your chats run in Open WebUI (self-hosted or company-hosted).

Automatic sync (recommended) ​

  1. In Open WebUI, open your profile (bottom left) → Settings → Account → API keys. Reveal and copy the API key.
  2. In MindBehindAI, open Integrations → Open WebUI.
  3. Paste your Open WebUI URL (only the main site—nothing after /).
  4. Paste the API key.
  5. Tap Save, then Sync enabled connections.

MindBehindAI updates Integrations → Tool servers in Open WebUI for this computer only—other machines are left alone.

Manual setup (same computer) ​

If MindBehindAI and Open WebUI run on the same computer, you can skip sync and add each tool by hand:

  1. On Home, under Links for other apps, tap Copy link for each connection.
  2. In Open WebUI, go to Admin → Settings → External tools (labels vary by version) and add one entry per link.

Tips ​

  • For MindBehind tool URLs on this computer, use the same http://127.0.0.1:… addresses as Home → Links for other apps (or run Sync enabled connections). That matches what the app writes and works reliably in the embedded Chat webview; plain localhost can fail there even when it works in a normal browser tab.
  • If Open WebUI runs inside Docker on the same machine, try http://host.docker.internal:PORT/… instead of loopback for reaching the host bridge.
  • After changing which connections are enabled, run Sync enabled connections again.
