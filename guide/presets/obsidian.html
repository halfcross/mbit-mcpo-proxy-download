Obsidian notes ​

The Obsidian preset links an assistant to one vault at a time—the folder Obsidian uses for that vault.

Learn more sheet ​

Key points:

  • Each connection is one vault.
  • Tap Choose and pick the same folder you open as a vault inside Obsidian.
  • For more than one vault, add the preset again and give each connection a clear name.

Official Obsidian MCP notes: mcp-obsidian.org/install.

Add connection dialog ​

  • Connection name — optional; leave blank to auto-name from the folder.
  • Vault folder — must be the vault root on disk.

After adding ​

Enable the connection, turn the bridge on, then Copy link on Home or sync through Open WebUI.
