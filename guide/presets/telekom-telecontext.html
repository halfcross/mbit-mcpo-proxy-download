Telekom Telecontext ​

Telekom Telecontext connects assistants to approved Telekom tools (for example Jira, GitLab, Confluence) through one MCP connection.

Before you begin ​

  • Your organisation must have Telekom Teleconsole access and your administrator must link accounts in the Telekom authorization portal when required.
  • In Teleconsole, finish Authorization services for every tool you plan to use—same scope you pick here.

Tap Open authorization portal in the app if your admin shared that link.

Add the connection ​

  1. Connections → Library → Telekom Telecontext → +.
  2. In the configurator, pick tool categories or use All tools if your policy allows it.
  3. Use Copy URL if an external system needs the generated MCP URL.
  4. Strip write tools is available when you want read-focused access—read the in-app How read-only works note.
  5. Large selections show a tool count warning—over about fifty tools can slow assistants down; prefer the smallest useful set.

Categories, Strip write tools, and Copy URL are all in the in-app configurator when you add the preset from the Library.

  1. Tap Add connection.

After adding ​

  • Enable the connection under My connections if it is not already on.
  • Turn the bridge on under Home, then Copy link or use Open WebUI sync.
