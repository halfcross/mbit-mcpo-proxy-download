Local Document Search (RAG) ​

MCP Local RAG lets your AI tools search through your own documents — PDFs, Markdown, DOCX, HTML, and code files — without sending anything to the cloud. Everything runs locally on your Mac.

How it works ​

  1. You choose a folder on your Mac that contains your documents.
  2. MCPBehindIT indexes those files using a local AI model (~90 MB, downloaded on first use).
  3. Your AI tools can then search and retrieve content from those documents through the MCP gateway.

All data stays on your machine: the index and the AI model are stored in the app data folder.

Step 1: Add from catalog ​

  1. Click Catalog in the sidebar.
  2. Find MCP Local RAG (it has the COMMUNITY and Local RAG tags).
  3. Click the + button.
  4. A dialog opens:

Step 2: Choose your folder ​

  1. Click Choose folder… and select the folder that contains the documents you want to search.
  2. Only this folder (and its subfolders) will be indexed and searchable.
  3. Click Add server.

What files are supported?

  • PDF
  • Markdown (.md)
  • DOCX (Microsoft Word)
  • HTML
  • Source code files

Binary files, images, and video are not indexed.

Step 3: Start the gateway ​

  1. Go to Home.
  2. Click Start (or Apply & Restart if the gateway is already running).
  3. On first use, the gateway downloads a small AI model (~90 MB). This happens once.

Step 4: Index your documents ​

  1. On the Dashboard, switch to the Documents tab.
  2. You'll see a list of files from your selected folder.
  3. Each file shows its indexing status:
    • Not indexed — the file hasn't been processed yet
    • Indexed — the file is searchable
  4. Click Select not indexed to select all files that haven't been indexed yet.
  5. Click Index selected to start indexing.
  6. Wait for the indexing to complete. Large folders may take a few minutes.

Step 5: Search in your AI tool ​

Once files are indexed, any AI tool connected to the gateway can use the search_tools function to find information in your documents.

For example, in Open WebUI you can ask:

"Search my documents for the latest quarterly report."

The AI will use Local RAG to find and return relevant passages from your indexed files.

Managing documents ​

Refreshing the file list ​

Click Refresh list on the Documents tab to rescan the folder. New files will appear as "not indexed."

Re-indexing ​

If you update a file, select it and click Index selected again to update the index.

Changing the folder ​

To change which folder is indexed:

  1. Go to Servers, click Edit on the Local RAG server.
  2. Update the document folder path.
  3. Apply & Restart on Home.
  4. Re-index the new folder.

Advanced: CLI & troubleshooting ​

The Documents tab has a CLI & advanced section (expand it at the bottom) with:

  • Status — shows the current state of the RAG engine
  • Raw list — the complete file list from the CLI
  • Ingest folder — manually trigger folder ingestion

These tools are for power users and support troubleshooting. Normal usage doesn't require them.
