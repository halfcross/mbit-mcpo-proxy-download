Telecontext (Telekom) ​

Telekom Telecontext is an enterprise MCP server that gives your AI tools access to Jira, GitLab, Confluence, and more — all through a single connection with OAuth sign-in.

Prerequisites ​

  • A Telekom Teleconsole account with the services you want to use activated.
  • Complete the Teleconsole Authorization services setup for each service (Jira, GitLab, etc.) before adding Telecontext.

Set up Teleconsole first

Telecontext connects to your enterprise tools through Teleconsole. If a service isn't authorized in Teleconsole, those tools won't work even if they're selected here.

Step 1: Add from catalog ​

  1. Click Catalog in the sidebar.
  2. Find Telekom Telecontext (it has the ENTERPRISE tag).
  3. Click the + button.
  4. The Telecontext configurator opens.

Step 2: Choose categories and tools ​

The configurator shows all available categories of tools. Each category contains multiple individual tools. There are 11 categories with over 100 tools in total.

Categories ​

CategoryToolsWhat it does
Knowledge1Query Deutsche Telekom IT's internal knowledge base and documentation through AI-powered chatbots.
Tardis3Search and inspect APIs on the TARDIS API platform — find APIs, get details, and retrieve OpenAPI specs.
Chatbot Factory2List and query Telekom chatbots you have access to through the Chatbot Factory.
PSA3Browse the Privacy & Security Assessment (PSA) document library — list subject areas, requirement documents, and individual security/data privacy requirements.
GitLab50Full GitLab integration: repositories, branches, commits, issues, merge requests (including discussions, approvals, merging), epics, CI/CD pipelines and jobs, projects, groups, wikis, and global search. Includes both READ and WRITE tools.
Jira33Full Jira integration: create/update/search/delete issues, manage sprints and boards, handle worklogs, link issues and epics, manage versions, transition issue status, and more. Includes both READ and WRITE tools.
Raccoon6Monitoring and observability: execute PromQL instant and range queries against Raccoon/VictoriaMetrics, list metrics, labels, and check server status.
LeanIX1Enterprise architecture management: retrieve factsheet information from LeanIX by ID, name, or email.
Confluence12Full Confluence integration: read and create pages, manage comments and labels, search content and users, view page statistics, and navigate page hierarchies. Includes both READ and WRITE tools.
Feedback2Submit and analyze feedback for agent performance.
Meta3Utility tools: search available tools by name, and call any tool by name with parameters (useful for dynamic tool discovery).

Services require Teleconsole authorization

Each category corresponds to a Teleconsole service. You must complete the Teleconsole Authorization services setup for a category before its tools will work. For example, to use GitLab tools, authorize the GitLab service in Teleconsole first.

Selecting tools ​

  • Check a category to include all its tools.
  • Expand a category (click the arrow) to see individual tools and select only the ones you need.
  • Each tool is labeled READ (non-mutating, just retrieves data) or WRITE (can modify remote state — create issues, merge requests, etc.).

Keep it focused

The more tools you enable, the more context your AI assistant needs to process. If you enable more than 50 tools, a warning appears:

"Tool count warning — Enabling more than 50 tools may impact performance and consume more context space. Consider selecting only the tools you need for your workflow."

A good starting point: enable Knowledge + Jira + Confluence for general enterprise use, or GitLab alone for development workflows. You can always come back and add more categories.

Read-only mode ​

The configurator shows a hint about read-only mode at the top. The URL it generates is what MCPBehindIT uses to configure the connection.

Step 3: Save ​

Click Save (or the confirm button). The server is added to your Servers list with the name telecontext.

Step 4: Start the gateway ​

  1. Go to Home.
  2. Click Start (or Apply & Restart if the gateway is already running).
  3. Watch the progress log as the gateway starts.

Step 5: OAuth sign-in ​

After the gateway starts, Telecontext requires you to sign in with your Telekom account.

What happens:

  1. The gateway connects to Telecontext and receives an OAuth authorization URL.
  2. MCPBehindIT detects this URL in the container logs.
  3. A notification toast appears at the bottom-right of the app window:
    • Title: "OAuth sign-in required"
    • Description: An MCP server needs you to sign in.
    • Buttons: Open in browser and Copy URL
  4. Click Open in browser. Your default browser opens to the Telekom sign-in page.
  5. Sign in with your Teleconsole credentials.
  6. After successful authentication, the browser shows a confirmation. Return to MCPBehindIT.

Browser didn't open?

Click Copy URL on the toast and paste it into your browser manually.

Step 6: Verify the connection ​

  1. Go to Logs and look for:
    Successfully connected to 'telecontext'
  2. Go to Home → Clients tab. You should see the telecontext server row with its URLs.
  3. Copy the OpenAPI URL and paste it into your AI tool to start using Telecontext.

Editing Telecontext ​

To change which categories or tools are active:

  1. Go to Servers.
  2. Click Edit on the telecontext row.
  3. The configurator reopens with your current selection.
  4. Make changes and save.
  5. Apply & Restart on Home.

Disabling Telecontext ​

Click Disable on the telecontext row in Servers if you want to temporarily exclude it without losing your configuration. Apply & Restart on Home.

OAuth re-authentication ​

OAuth tokens expire. When they do, the gateway automatically requests a new authorization URL, and the OAuth toast appears again. Just sign in again — your tool selection is not affected.
