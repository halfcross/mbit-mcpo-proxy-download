The Dashboard ​

The Dashboard is the home screen of MCPBehindIT. It gives you a quick overview of everything: Docker status, gateway state, your servers, and connection URLs.

Layout ​

Status badge (top-right) ​

The colored dot in the top-right corner shows the overall state at a glance:

BadgeMeaning
Running (green)Gateway is up and serving requests
Stopped (gray)Gateway is not running
Error (red)Something went wrong — check the stack card for details
Starting… / Pulling… (yellow)Gateway is starting or pulling the Docker image

Phase strip ​

The horizontal bar below the heading shows three phases:

  1. DOCKER — Is Docker Desktop reachable?
  2. GATEWAY — Is the gateway container running?
  3. SERVERS — How many server profiles exist and how many are enabled?

Each phase has a colored dot: green (ok), gray (inactive), or red (problem).

Three tabs ​

TabWhat it shows
StackGateway controls — Start, Stop, Apply & Restart. Error messages and progress logs appear here.
ClientsConnection URLs for each enabled server. Appears once the gateway has run at least once.
DocumentsLocal RAG file explorer — index, refresh, and manage your document files.

Stack tab ​

This is the default view. It contains:

  • Tool gateway card — Current status and action buttons.
  • Quick stats (when running) — Number of server profiles, how many are active, and the base URL.

Error states ​

If Docker is unavailable, the card shows an error with a Details expander:

If the port is already in use, you'll see a message suggesting to either stop the other process or change the port in Settings.

Clients tab ​

Once the gateway has started at least once, the Clients tab shows:

  • A URL table with one row per enabled server. Each row has buttons to:
    • Copy base — the server's base URL
    • Copy OpenAPI — the OpenAPI spec URL (what you paste into Open WebUI)
    • Copy OpenAPI JSON — the raw JSON spec URL
    • Open docs — opens the interactive API docs in your browser
  • Bulk copy — copy all base URLs or all OpenAPI URLs at once.
  • Open WebUI — expandable step-by-step instructions for connecting to Open WebUI.

See Connecting Your Tools for a detailed walkthrough.

Documents tab ​

If you've added the MCP Local RAG server, the Documents tab shows a file explorer with:

  • A list of files in your indexed folder
  • Status for each file (indexed / not yet indexed)
  • Buttons to Refresh list, Index selected, and Select not indexed

See Local Document Search for setup instructions.
